- Una vez que ya tenemos la aplicación creada, si la vamos a ejecutar por primera vez:

	> gradle wrapper (en la carpeta del proyecto)

- Al hacer esto se creará el archivo gradlew y también el archivo gradlew.bat

- Después de eso tenemos que darle permisos al archivo gradlew con el comando:

	> chmod +x gradlew

- Después de esto ya podemos ejecutar el siguiente comando para iniciar la aplicación:

	> ./gradlew run

- Los pasos de chmod y anterior solo son necesarios la primera vez, luego solo hace falta el gradlew run.
